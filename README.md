# Primera Visita

Landing page estática de home staging para Tucumán y Yerba Buena.

## Ver el sitio

Abrí `index.html` directamente en el navegador o iniciá un servidor local desde esta carpeta, por ejemplo:

```powershell
python -m http.server 8000
```

Luego visitá `http://localhost:8000`.

## Imágenes

Los lugares reservados se encuentran en las clases `.image-placeholder`. Para reemplazarlos, agregá las fotos dentro de una carpeta `assets/` y cambiá el fondo o el contenido de esos contenedores. Las fotos se muestran en blanco y negro mediante CSS.

El Instagram está configurado como placeholder `@USUARIO` y debe reemplazarse en `index.html`.
